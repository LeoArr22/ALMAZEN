Políticas de Criptografía

Hasheo Seguro (Bcrypt)

Las contraseñas se interceptan en la capa de servicio y se transforman mediante un algoritmo criptográfico antes de guardarse en la base de datos. Nadie puede verlas en texto plano.

Trazabilidad de Caja

Toda apertura, cierre de turno de caja o confirmación de venta quedará encuadrada de forma inmutable al ID del usuario que inició la sesión.
API Target: POST /usuarios/registrar
Filtro de Seguridad: Depends(solo_admin)
